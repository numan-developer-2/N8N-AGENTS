## How to Use

1. Open the category folder that matches your integration or automation idea.
2. Copy the workflow/template content from the `.txt` file.
3. Import or recreate it in n8n.
4. Replace placeholder credentials, API keys, URLs, sheet IDs, and webhook values with your own secure n8n credentials.

## Notes

- Do not commit real API keys, access tokens, passwords, or private credentials.
- Many templates intentionally contain placeholders such as `YOUR_API_KEY`, `YOUR_TOKEN`, or similar values.
- Review every workflow before using it in production.
