## How to Use

1. Open the category folder related to your use case.
2. Choose a workflow template from the `.txt` files.
3. Review the workflow logic, nodes, credentials, and API requirements.
4. Import or recreate the workflow inside n8n.
5. Replace placeholders such as `YOUR_API_KEY`, `YOUR_TOKEN`, `YOUR_SHEET_ID`, and webhook URLs with your own secure credentials.
6. Test the workflow in a safe environment before using it in production.

## Security Notes

- Real API keys, passwords, tokens, and private credentials should never be committed to this repository.
- Templates may contain placeholder values for demonstration purposes.
- Production workflows should use n8n credential storage instead of hardcoded secrets.
- Every workflow should be reviewed before being connected to live business systems.
